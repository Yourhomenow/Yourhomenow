## How I work

- Feature branches into `develop`, then `main`, with conventional commits (`feat:`, `fix:`, `chore:`).
- When something breaks, I isolate the layer: test the API with `curl`, the database with its own CLI, then the app.
- Validate input, hash passwords, and keep secrets in `.env`, never in the repo.
